# Hello-World

A presentation demonstration of the progression from a **static button** through **simulated intelligence** to **real empathic AI**, framed within the broader study of AI systems and human–computer interaction.

## Demo

Open `index.html` in any modern browser.  No build step or server required — it runs entirely in the browser.

## Three-Stage Progression

| Stage | Concept | Key Characteristic |
|-------|---------|-------------------|
| ① Static Button | Deterministic output | Every user receives the identical hardcoded response |
| ② Simulated Intelligence | Rule-based / keyword matching | Branching logic creates the *appearance* of understanding |
| ③ Empathic AI | Sentiment-aware, emotionally intelligent | Tone, context, and feeling all shape the response |

## Purpose

This demo accompanies a narrative on the evolution of human–computer interaction — from the most primitive one-shot trigger to an affective computing system that reads emotional valence and responds with empathy.
